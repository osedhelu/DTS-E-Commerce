8. FLUJO DE EJECUCIÓN
================================================================================

1. Usuario toca botón "Continuar con Google"
   └─ LoginScreen._signInWithGoogle()

2. Se ejecuta GoogleSignInUseCase.call()
   ├─ Limpia sesiones previas (signOut, disconnect)
   ├─ GoogleSignIn.signIn() <- Abre selector de cuentas
   ├─ Obtiene tokens: accessToken + idToken
   └─ Verifica idToken no esté vacío

3. Crea credencial de Firebase
   └─ GoogleAuthProvider.credential(accessToken, idToken)

4. Autentica en Firebase
   └─ FirebaseAuth.signInWithCredential()

5. Obtiene token de Firebase
   └─ FirebaseAuth.currentUser.getIdToken()

6. Envía al backend DTS
   ├─ POST /accounts/auth/google/
   ├─ Body: { "id_token": firebaseIdToken, "role": "driver" }
   └─ Respuesta: { access_token, refresh_token, user }

7. Guarda tokens localmente
   └─ TokenStorage.saveTokens() -> Flutter Secure Storage

8. Navega a home
   └─ PostAuthService.complete()

12. ERRORES COMUNES Y SOLUCIONES
================================================================================

ERROR 1: "Google no devolvió idToken"
  CAUSA: serverClientId mal configurado
  SOLUCIÓN: Verificar DefaultFirebaseOptions.googleServerClientId
            Debe ser el Web OAuth Client (type 3) de google-services.json

ERROR 2: "Esta cuenta no es de conductor"
  CAUSA: Usuario existe en Firebase pero sin rol driver
  SOLUCIÓN: Backend validando en /accounts/auth/google/
            Asegurar que usuario está marcado como driver

ERROR 3: Google Sign-In no aparece en release
  CAUSA: SHA-1 de release no registrado en Google Cloud
  SOLUCIÓN: 1. Generar keystore de release
            2. Obtener SHA-1: keytool -list -v -keystore release.jks
            3. Registrar en Google Cloud Console
            4. Actualizar build.gradle.kts

ERROR 4: iOS URL Scheme no funciona
  CAUSA: URL Scheme en Info.plist incorrecto o no registrado
  SOLUCIÓN: Verificar que Info.plist tenga:
            CFBundleURLSchemes = com.googleusercontent.apps.1015036938407-...

ERROR 5: Firebase no inicia
  CAUSA: Firebase.initializeApp() no ejecutado
  SOLUCIÓN: Verificar main.dart antes de runApp()
