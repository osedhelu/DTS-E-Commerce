7. FLUJO COMPLETO DE TOKENS
================================================================================

Paso 1: Usuario Selecciona Cuenta Google
┌─────────────────────┐
│ GoogleSignIn.signIn │ ← Abre selector de cuentas (UI del OS)
└─────────────────────┘
         ↓
    Usuario confirma

Paso 2: Obtiene Tokens de Google
┌────────────────────────┐
│ GoogleSignInAccount    │
├────────────────────────┤
│ .authentication        │
│  ├─ accessToken        │ (para Google APIs)
│  └─ idToken ✓          │ (signed JWT con claims del usuario)
└────────────────────────┘

Paso 3: Intercambia con Firebase
┌──────────────────────────────┐
│ GoogleAuthProvider.credential│
│ (accessToken, idToken)       │
└──────────────────────────────┘
         ↓
┌────────────────────────────────────┐
│ FirebaseAuth.signInWithCredential()│ ← Valida contra Google
└────────────────────────────────────┘
         ↓
┌────────────────────────────┐
│ FirebaseAuth.currentUser   │ ← Usuario autenticado en Firebase
│  .getIdToken()             │ ← Firebase JWT token (app-specific)
└────────────────────────────┘

Paso 4: Envía a Backend DTS
┌──────────────────────────────────────┐
│ POST /accounts/auth/google/          │
│ {                                    │
│   "id_token": firebaseIdToken,       │
│   "role": "driver"                   │
│ }                                    │
└──────────────────────────────────────┘
         ↓
┌────────────────────────────────────────┐
│ Backend:                               │
│ 1. Verifica idToken contra Firebase    │
│ 2. Extrae claims: sub (user ID)        │
│ 3. Valida que usuario sea conductor    │
│ 4. Crea/Actualiza usuario en DTS       │
│ 5. Genera JWT tokens (access+refresh)  │
└────────────────────────────────────────┘
         ↓
┌──────────────────────────┐
│ Response                 │
│ {                        │
│   access_token: "...",   │
│   refresh_token: "...",  │
│   user: { ... }          │
│ }                        │
└──────────────────────────┘
         ↓
┌────────────────────────────┐
│ Flutter Secure Storage     │
│ (KeyChain iOS/KeyStore A)  │
└────────────────────────────┘


8. ERROR HANDLING CHAIN
================================================================================

Login Screen
└─ _signInWithGoogle()
   └─ try { ... }
      ├─ GoogleSignInUseCase.call()
      │  ├─ GoogleSignIn.signIn() == null
      │  │  └─ throw StateError('cancelado')
      │  │
      │  ├─ googleAuth.idToken == null
      │  │  └─ throw StateError('revisa serverClientId')
      │  │
      │  └─ FirebaseAuth no retorna token
      │     └─ throw StateError('no se pudo obtener token')
      │
      ├─ AuthRemoteDataSource.signInWithGoogle()
      │  ├─ DioException.response?.data['detail']
      │  │  └─ throw StateError(detail)
      │  │
      │  └─ rethrow DioException
      │
      └─ catch (NotADriverException)
         └─ "Esta cuenta no es de conductor"
      
      └─ catch (other)
         └─ _friendlyAuthError(e)
            └─ Muestra mensaje amigable en UI
